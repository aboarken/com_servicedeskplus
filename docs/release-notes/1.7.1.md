# com_servicedeskplus 1.7.1

Install `com_servicedeskplus.zip` (attached below) through **System → Install → Extensions**, or update from **System → Update → Extensions** if 1.7.0 is installed. No database schema changes.

## Fixes
- **Clearer message when ServiceDesk Plus refuses an approval.** When ServiceDesk Plus answers "You are not authorized to take action on this approval" (code 4201), users now see "ServiceDesk Plus did not allow this decision. Please contact IT." instead of a generic error.
- **Fewer errors from short connection drops.** A read from ServiceDesk Plus that fails to connect, for example a dropped TLS handshake, is tried once more. Creating requests and approving or rejecting are never repeated automatically.

## Changes
- "The service desk did not accept the data that was sent." now reads "ServiceDesk Plus did not accept the data that was sent."
- The component log (`administrator/logs/com_servicedeskplus.php`) now records the exact cURL error for connection failures, to help diagnose certificate problems.
