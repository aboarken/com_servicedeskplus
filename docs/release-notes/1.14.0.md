# com_servicedeskplus 1.14.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Dashboard
A new menu item type, **Dashboard** (*Menus → Add New Menu Item → ServiceDesk Plus → Dashboard*), shows the user's figures. Click a figure to open its page with the matching filter.

| Section | Figures |
|---|---|
| My requests | All requests, and one per status of the My Requests filter (Open, On Hold, Resolved, Closed, …) |
| My approvals | Waiting for my approval · Approved by me · Rejected by me |
| My loans | All my loans · To return within 30 days (including overdue) · Overdue |
| Announcements | Current announcements |

- The request figures follow the statuses listed under **Integration Settings → Request statuses**. To see *Canceled* requests, add the status there, spelled exactly as in ServiceDesk Plus.
- *Approved by me* and *Rejected by me* count decisions made through the portal; decisions made directly in ServiceDesk Plus are not known to the portal.
- Each section only shows for users with the permission of its page.

## My Approvals and My Loans look like My Requests
Both pages now have the same filter bar as My Requests: search, *Show*, sort and a Search button. Each has a striped table with the ID first, where the ID and the subject or name open the item, and pages of 25.
- **My Approvals → Show:** waiting for my approval, approved by me, rejected by me, all my decisions.
- **My Loans → Show:** all my loans, to return within 30 days, overdue.

## Removed
The row of links between portal pages (added in 1.13.0) is removed.
