# com_servicedeskplus 1.5.0

First release published on GitHub. Install `com_servicedeskplus.zip` (attached below) through **System → Install → Extensions** in Joomla 6.2 (PHP 8.3+). Upgrading from 1.4.0 keeps your settings and user mappings and makes no database changes.

## New Request form
- The menu item type is now called **Request Form**, and the page title is **New Request**.
- The submit button now says **Submit**.
- **Cancel** is now a grey button that matches the Search button.
- **Attachment limits are now 3 files and 1 MB per file (3 MB in total).** Before, they were 5 files, 10 MB each and 20 MB in total.
  - The server enforces these limits, so a modified form or a crafted request can't get around them. The server measures the size of the uploaded file itself rather than trusting the size the browser reports. It counts every file sent toward the limit, even invalid ones.
  - The form checks files as soon as they are chosen, and the help and error messages always show the limits the server enforces.

## My Requests
- The button at the top right now says **Submit a Request**.
- **Fixed:** on tablets and small desktops the Search button's label overflowed or wrapped. The filter bar now adapts to the screen width, and the button is grey and the same height as the inputs.
- The status filter now shows **Open** requests by default. If you choose "All statuses", that choice stays when you move between pages.

## Request details
- Now shows **Urgency**, **Technician Group**, **Subcategory** and **Item**, taken from the ServiceDesk Plus request.

## Notes
- Existing menu items keep the titles you gave them in Joomla. Only the name of the menu item type has changed.
- If your PHP `upload_max_filesize` is below 1 MB, raise it so users can upload files up to the full limit.
