# com_servicedeskplus 1.8.0

Update from **System → Update → Extensions** (1.7.0 or later), or install `com_servicedeskplus.zip` (attached below) through **System → Install → Extensions**. No database schema changes.

## Approve and reject from Joomla
ServiceDesk Plus only accepts an approval decision from the assigned approver, so decisions sent with the portal's API technician key were refused ("You are not authorized to take action on this approval"). This release adds a workaround that needs no API keys for employees:

1. Enter the API technician's e-mail (for example APIAdmin's) under **Integration Settings → Approvals → API technician e-mail**.
2. When an approver clicks **Approve** or **Reject** in Joomla, the portal checks that they are the assigned approver, then records the decision under the API technician on the same approval level.
3. The approval comment reads "Approved by *name* via the Joomla portal." followed by the approver's comment, and a private request note (not shown to the requester) names who decided.
4. The approver's own pending entry is removed, so the level shows a single decision.

Things to know:
- In ServiceDesk Plus the decision appears under the API technician; the real approver is named in the comment and the note.
- Approval levels that need **all** approvers still wait for the others. The approver is told so.
- If ServiceDesk Plus already accepts decisions from the API technician directly, nothing extra happens.
- Leave the e-mail empty to keep the previous behaviour.
- Purchase request and purchase order approvals are not covered.

## Other changes
- Approval comments are sent as one line of at most 250 characters, as ServiceDesk Plus requires. The comment box now allows 200 characters.
