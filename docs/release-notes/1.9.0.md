# com_servicedeskplus 1.9.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below) through **System → Install → Extensions**. No database schema changes.

## Approvals for changes, releases and purchase orders
- **My Approvals** now lists approvals for **changes, releases and purchase orders** next to requests, with a new *Type* column.
- The approval page shows the change, release or purchase order (title, description, requester), and **Approve** / **Reject** work for all of them, including the API technician workaround introduced in 1.8.
- Problems are not included: ServiceDesk Plus has no approvals for problems.

**Before using it:** give the API technician's role permission to manage approvals in each module you use (changes, releases, purchase orders), as you did for requests.

## Faster My Approvals
The list now comes from a single ServiceDesk Plus call instead of scanning the 50 most recent requests (up to 101 calls). If your ServiceDesk Plus build does not support that call, the previous scan runs automatically, so request approvals keep working as before; changes, releases and purchase orders then need the new call.
