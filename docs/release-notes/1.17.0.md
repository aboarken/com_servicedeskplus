# com_servicedeskplus 1.17.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## New Dashboard design
- **Summary cards** with a coloured edge and number: blue *Open requests*, amber *On Hold requests*, purple *Waiting approval* (green when nothing waits), *Loans to return* red when a loan is overdue, amber when one is due soon, green otherwise, and teal *Announcements*. Cards lift on hover; the whole card is a link.
- **Announcements** and **Recent Requests** in panels with a *View all* link, coloured type badges and status badges (blue Open, amber On Hold).
- **My Requests:** two tiles, *Open* and *On Hold*, each with its service and incident count, and *+ Submit a Request*.
- **My Approvals** and **My Loans:** lists with coloured counts: green for approved and for nothing overdue, red for overdue, grey for zero.

The Dashboard has its own styles, so it looks the same on any site template.

## My Requests filter
The filter is now called **Request type**, with the options *All types*, *Incident* and *Service*.
