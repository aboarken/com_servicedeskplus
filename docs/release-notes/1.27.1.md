# com_servicedeskplus 1.27.1

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes. **Needed for approving purchase orders from the portal.**

## Fixed
- **Purchase order approvals stay approved.** The decision is recorded under the API technician and nothing is removed afterwards. Before, removing the approver's old entry made ServiceDesk Plus restart the approval (status *Open*, entries *To Be Sent*).

## What you may notice
- On an approved purchase order, ServiceDesk Plus shows the API technician's entry as *Approved*; the original approver's entry stays as ServiceDesk Plus leaves it.
- Purchase orders that were reset by earlier versions need to be submitted for approval again in ServiceDesk Plus.
