# com_servicedeskplus 1.28.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## New
- **Purchase order approvals show the purchase order:** vendor, who requested it, dates, the items with quantities and prices, and the totals.
- **Purchase order attachments** can be downloaded from the approval page.
- **"Back to …" is a button** in the same style as the page numbers.
- **Messages above the page title:** the result of an approval ("Your decision was recorded…", or an error) appears at the top of My Approvals and of the approval page.
