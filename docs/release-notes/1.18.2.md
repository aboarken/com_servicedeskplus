# com_servicedeskplus 1.18.2

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Approval comment wording
When someone approves or rejects from the portal and writes a comment, ServiceDesk Plus now shows the comment right after the portal line:

> Approved by (a.moussa) (ADB) Ahmad Mohamad Moussa via the Joomla portal: I already did that.

Before, it read "... via the Joomla portal. Custom comment: I already did that." Without a comment the line is unchanged ("... via the Joomla portal."). Decisions made earlier keep their old wording in ServiceDesk Plus.
