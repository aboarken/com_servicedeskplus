# com_servicedeskplus 1.21.1

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Fixed
- **"Could not update just now" on every page.** On sites whose template adds the component name to the page `<body>` (e.g. Helix Ultimate), the background update of 1.21.0 mistook the whole page for the portal content: the note appeared above the site header and the page was never updated. It now finds the portal content reliably, so pages update as intended.

## Changed
- If a page still cannot be updated, the note now says why (for example *"ServiceDesk Plus could not be reached"* or *"HTTP 500"*).
