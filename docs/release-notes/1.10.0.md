# com_servicedeskplus 1.10.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). This version adds two columns to the portal's audit table; Joomla applies the change automatically during the update.

## My past decisions
- New **Approval For** and **Subject** columns show what each decision was about (request, change, release or purchase order, and its title).
- Decisions made before this version have no stored subject and show "—".

## Clearer approval comments in ServiceDesk Plus
The comment recorded with each decision now reads:

> Rejected by (ADB) Ahmad Mohamad Moussa via the Joomla portal. Custom comment: Testing this approval.

The Joomla username is shown in brackets before the person's name, and the approver's own text follows "Custom comment:" (left out when they wrote none).
