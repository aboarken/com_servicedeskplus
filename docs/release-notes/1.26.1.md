# com_servicedeskplus 1.26.1

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Fixed
- **Purchase order approvals** no longer stop with "ServiceDesk Plus sent an answer that could not be read" after the API technician is added as approver; the decision is recorded.
- A retry reuses the API technician's approval entry that was left *To Be Sent*, instead of adding a second one.

## What you may notice
- Purchase order 34501 (or any other left *To Be Sent* by the earlier error) can simply be approved again from the portal.
