# com_servicedeskplus 1.20.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Faster pages
- **Connections are reused.** Until now every read from ServiceDesk Plus opened a new connection (DNS lookup, connect, TLS handshake). Now a page load opens it once and reuses it, which speeds up every portal page. Certificate checks, pinning and *Connect via* work as before.
- **Approvals are checked in parallel.** My Approvals and the Dashboard read the approvals of every record waiting for approval. These reads are now sent several at a time. On a test server answering in 100 ms, the check went from 10.8 s to 2.6 s.

New setting: **Integration Settings → Limits → Parallel API calls** (default 6; 1 = one after another, as before). Lower it if ServiceDesk Plus answers "too many requests".

## See where the time goes
- The log `administrator/logs/com_servicedeskplus.php` now shows, for each call, how long DNS, connect, TLS and ServiceDesk Plus took, and one summary line per page load with the number of calls and the total waiting time.
- **Find Endpoints → Run Diagnostics** has a new *Timing* section. A high "ServiceDesk Plus" time means the server itself is slow to answer; high DNS, connect or TLS times point to the network, firewall or certificate setup.
