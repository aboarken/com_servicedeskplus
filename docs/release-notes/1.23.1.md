# com_servicedeskplus 1.23.1

Security and clean-up release after an audit of the whole component. Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes. **Updating is recommended.**

## Security
- **Confirm checks the e-mails again:** a mapping is only confirmed when the ServiceDesk Plus user found for the account still has the account's current Joomla e-mail. To link different addresses on purpose, open the mapping and save it.
- **A request, loan, approval or announcement page is never shown from older saved results** (the Dashboard and the lists still open at once and then update).
- **Confirmed mappings are checked against ServiceDesk Plus once a day** and suspended when the ServiceDesk Plus user is gone or its e-mail changed.
- **Saved results are deleted** when a user's mapping is suspended, changed or matched again, and when the ServiceDesk Plus address changes.
- Without JavaScript, pages reload once to show current data.

## Other
- The installer checks for the PHP cURL extension.
- New `SECURITY.md`: how to report a security problem privately.
- Small fixes and removal of unused code; see the changelog.

## What you may notice
- *Confirm* can answer "Not confirmed: the e-mail … differs". Check the person; if it is the right one, open the mapping and save it, otherwise use *Match again*.
- A mapping you confirmed can become *Suspended* later if that person's e-mail changes in ServiceDesk Plus or their ServiceDesk Plus user is removed.
