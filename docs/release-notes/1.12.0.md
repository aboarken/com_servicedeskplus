# com_servicedeskplus 1.12.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Announcements
A new menu item type, **Announcements** (*Menus → Add New Menu Item → ServiceDesk Plus → Announcements*), lists ServiceDesk Plus announcements, newest first, with date, type, priority and a short preview. Each announcement opens on its own page.

**Who sees what**
- **Joomla permission:** give the user groups that should see announcements the new **View announcements** permission (*System → Global Configuration → ServiceDesk Plus → Permissions*). It is not granted by default; users without it get "not authorised".
- **ServiceDesk Plus visibility:** only announcements ServiceDesk Plus shows to requesters are listed:
  - public announcements, inside their display period (from / to date);
  - announcements limited to user groups, only for users whose ServiceDesk Plus record lists one of those groups;
  - technician-only announcements never appear.

## My Dashboard removed
The My Dashboard page is removed. Updating deletes its files and moves existing *My Dashboard* menu items to the trash.
