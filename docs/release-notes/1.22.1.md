# com_servicedeskplus 1.22.1

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Dashboard charts
- **Requests by Status:** the Open bar is visible again when there are thousands of closed requests. Active (Open, On Hold) and Completed (Resolved, Closed) are drawn on their own scales.
- **Open Requests by Age** is now a donut chart, with the total in the middle.
- **Open Requests by Priority** is now one colour bar split by priority. Each priority always keeps the same place and colour.
- *Show figures* is removed; large numbers have thousands separators (26,922).
