# com_servicedeskplus 1.25.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Dashboard
- **Who Is Handling My Requests** replaces *Requests by Status* (which repeated the My Requests tiles): the user's open and on-hold requests per technician, with *Other technicians* and *Not assigned yet*.
- **Open Requests by Age** in warm colours, from light gold (newest) to deep red (oldest).

## What you may notice
- Right after updating, the new chart can say "Shown after the next update of the Dashboard." until the page has refreshed its data.
