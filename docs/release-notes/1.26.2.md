# com_servicedeskplus 1.26.2

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes. **Recommended for everyone who approves purchase orders from the portal.**

## Fixed
- **Purchase order approvals:** the portal now waits until ServiceDesk Plus has sent the approval e-mail to the API technician, then approves, and checks that ServiceDesk Plus really shows the decision.
- **The approver's own entry is never removed unless the decision is recorded.** Otherwise nothing changes and the user is told the decision was not recorded.
- The log explains a failed approval e-mail (mail server, or no e-mail address for the API technician).

## What you may notice
- Approving a purchase order can take a few seconds longer.
- Purchase orders affected before this update (for example 35104) need their approver added again, or a decision, in ServiceDesk Plus.
