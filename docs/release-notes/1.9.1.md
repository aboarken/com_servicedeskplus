# com_servicedeskplus 1.9.1

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database schema changes.

## Fixes
- **Changes, releases and purchase orders now appear in My Approvals.** ServiceDesk Plus's combined approvals list only returns the API technician's own approvals, so 1.9.0 found nothing for other users. The portal now checks each module directly.
- **Approvals of closed requests** are no longer listed: ServiceDesk Plus does not allow changing the approvers of a closed record, so these approvals cannot be decided from the portal. If it happens anyway, the message says so instead of a generic error.

## New setting
**Integration Settings → Approvals → Show approvals for**: tick the modules whose approvals My Approvals should list (all four by default). Untick modules you do not use: each one adds ServiceDesk Plus calls when the list loads.

## Other changes
- The type column in My Approvals is now **Approval For**, with a coloured label for Request, Change, Release and Purchase order.
- The refusal message now ends with "Please contact the System Administrator."
