# com_servicedeskplus 1.11.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## My Dashboard
A new menu item type, **My Dashboard** (*Menus → Add New Menu Item → ServiceDesk Plus → My Dashboard*), shows on one page:
- **At a glance:** open requests, overdue requests, approvals waiting for me and overdue loans.
- **My requests:** service requests and incident requests by status (Open, On Hold, Resolved, Closed) with totals, and the five most recent requests.
- **Waiting for my approval:** by type (request, change, release, purchase order — the types ticked under Integration Settings → Approvals).
- **My loans:** total and overdue.

Each part only shows when the user may see the matching page. The counts cover the user's 1000 most recent requests.

## Conversation on request pages
Opening a request in My Requests now shows its **conversation**: the e-mails and notes, oldest first. The approval page of a request shows the same conversation, so approvers see the whole exchange before deciding. Only items ServiceDesk Plus marks as visible to the requester are shown; technicians' internal notes stay hidden.

## Backend addresses
- `index.php?option=com_servicedeskplus&view=settings` → `view=integrationsettings`
- `index.php?option=com_servicedeskplus&view=usermaps` → `view=usermappings`

The backend menu uses the new addresses; old links and bookmarks are redirected.
