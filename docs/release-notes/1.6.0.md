# com_servicedeskplus 1.6.0

Install `com_servicedeskplus.zip` (attached below) through **System → Install → Extensions** in Joomla 6.2 (PHP 8.3+). Upgrading from 1.5.0 keeps your settings and user mappings and makes no database schema changes.

## Simpler Settings page
- **Removed the Approvals section** (*Pending approval status* and *Requests checked for approvals*). My Approvals keeps working with the built-in values, which match a standard ServiceDesk Plus setup: approvals in the "Pending Approval" status, checked across the 50 most recent requests waiting for approval. Saved values of these options are removed when you upgrade.
- **Removed the Test asset endpoint button.** It was a one-time diagnostic for the asset API; My Loans is not affected. **Test connection** and **Read certificate pin** are still available.

## Notes
- If your ServiceDesk Plus uses a renamed approval status (not "Pending Approval"), My Approvals will no longer find pending approvals after this upgrade. Stay on 1.5.0 in that case and let us know.
