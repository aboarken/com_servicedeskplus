# com_servicedeskplus 1.19.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Find Endpoints
A new administrator page, *Components → ServiceDesk Plus → Find Endpoints* (also a button on Integration Settings), shows which ServiceDesk Plus API endpoints your server offers and what they return:

- **Diagnostics:** one click checks the connection, reads a few rows of every endpoint the portal uses and checks the other known endpoints. Enter a requester's e-mail to also check that the portal can match that person and finds their requests and assets. Copy the report and send it to whoever supports the portal.
- **Known API Endpoints:** the REST API v3 list endpoints, the portal's own first. *Check which endpoints answer* shows, for each, whether the API technician can read it and how many records it has.
- **Check an Endpoint:** read any `/api/v3` path, optionally filtered by one field (e.g. `status.name` = `Open`), and see its field paths, the kind of value in each and the status texts.

Only field paths, kinds of values, counts and status texts are shown, never names, e-mails, subjects or other personal values. Only reading requests are sent. The page needs Super User rights; checks are limited to 60 per hour and recorded in the audit log.
