# com_servicedeskplus 1.8.1

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below) through **System → Install → Extensions**. No database schema changes.

## Fix: approving from Joomla
In 1.8.0, approving through the API technician stopped with "Recommendation mail is not yet sent.": ServiceDesk Plus accepts no decision on an approval until its approval e-mail has been sent. The portal now sends that e-mail right after adding the API technician as approver, then records the decision.

- The e-mail goes to the API technician's mailbox and says that the assigned approver decided via the Joomla portal. It needs no action.
- The API technician's role must allow editing requests and managing their approvals (adding, sending and removing approvers).
