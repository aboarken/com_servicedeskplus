# com_servicedeskplus 1.12.1

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Internal announcements for technicians
Announcements created for the team (not public) were hidden from everyone. They are now shown to **technicians**: users whose ServiceDesk Plus record is a technician. Technicians see every announcement in its display period; requesters still see public announcements, and group announcements only for their own groups.

Still not seeing an announcement? Open `administrator/logs/com_servicedeskplus.php`. Each time Announcements is loaded, a line says how many announcements were read, shown and hidden, and why (outside display period, internal, or other user groups).

## Wording
Messages now name **ServiceDesk Plus** instead of "the service desk", for example *"The ServiceDesk Plus did not allow this action."*
