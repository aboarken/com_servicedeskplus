# com_servicedeskplus 1.24.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## New
- **New users are approved automatically again.** *Integration Settings → Users → New users*:
  - **Approve automatically** (default): a user whose Joomla e-mail matches a ServiceDesk Plus user can use the portal at once.
  - **Wait for administrator approval:** every new match waits until you confirm it in *User Mappings* (the 1.23.0 behaviour).
  With both choices, a user whose e-mail **changes** later is suspended until you approve it.
- **Attachments on the approval page:** the files of the request, change or release being approved, ready to download. Only approvers of that record can download them.

## Fixed
- My Approvals opens on **All types** again after a reload or Back (the browser no longer restores the previous choice). The same for the other lists.

## What you may notice
- Users who were *Waiting for approval* are matched on their next visit.
