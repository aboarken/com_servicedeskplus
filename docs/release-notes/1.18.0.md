# com_servicedeskplus 1.18.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes. After updating, reload pages with Ctrl+F5 so the browser loads the new styles.

## Dashboard
- **Resolved** and **Closed** tiles in the *My Requests* block, next to *Open* and *On Hold*. ServiceDesk Plus counts them without the portal reading those requests, so the Dashboard stays fast.
- Each tile lists **incidents first, then service requests**.
- *Open* is shown in **#17426f** everywhere.

## Same design on every page
My Requests, My Approvals, My Loans, Announcements, the request, approval, loan and announcement pages and the request form now use the Dashboard's design: panels, coloured status badges, a conversation timeline, and green *Approve* / red *Reject* buttons.

## Filters without a Search button
Choosing an option in a filter applies it straight away. Type a search and press **Enter**.
