# com_servicedeskplus 1.18.1

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes. Reload pages with Ctrl+F5 after updating.

- **Dashboard:** the Announcements panel shows the **End date** of each announcement ("No end date" when there is none).
- **Filter bars:** every list is as wide as its longest option, so **Waiting for my approval** on *My Approvals* is shown in full. On narrow screens the fields wrap to a second line.
- **Announcements list:** the **Posted by** column is removed; it is still shown when you open an announcement.
