# com_servicedeskplus 1.15.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Cache time in minutes — and why the Dashboard was slow
*Integration Settings → Limits → **Cache time (minutes)***, 0 to 60, default **5**.

With the cache at 0, every page load reads ServiceDesk Plus again. The Dashboard makes the most calls: it finds waiting approvals by scanning requests, changes, releases and purchase orders, and reads requests, loans and announcements. With a cache, only the first load in each period is slow; the next loads are instant. A user's own new requests and approval decisions still show at once.

An existing value in seconds is converted, rounded up, until the settings are saved. **If you had 0, set 5 and save.**
