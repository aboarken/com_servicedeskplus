# com_servicedeskplus 1.16.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## New repository address
The repository is now `aboarken/servicedeskplus`. This version's update server and changelog point to the new address; Joomla stores it when you install this update. GitHub redirects the old address, so sites on older versions still find this update.

## Faster Dashboard
Only open and on-hold requests are read from ServiceDesk Plus (up to 500 of each). Resolved, closed and canceled requests are no longer counted, so the Dashboard no longer slows down for users with a long history.

## Dashboard layout
- *On Hold requests* card instead of *Overdue requests*.
- *Recent Requests* (open and on-hold only) under *Announcements*, with the same heading size.
- *My Requests*, *My Approvals* and *My Loans* side by side in three columns (stacked on phones), with the same tables as before.

## My Requests: filter by type
*Type* — all types, incident or service request — between *Search* and *Status*.

## Loan details
A loan's page also shows the purchase date, warranty expiry date, department and the user it is loaned to (— when ServiceDesk Plus has no value).

## Any site template
The portal pages follow the installed site template instead of relying on Cassiopeia. Templates without Bootstrap get plain fallback styles; templates with their own styles always win. The pagination and conversation layouts can now be overridden in the template.
