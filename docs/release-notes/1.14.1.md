# com_servicedeskplus 1.14.1

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Dashboard: the 1.11 design is back
- **Summary cards:** open requests · overdue requests · waiting for my approval · loans to return within 30 days · current announcements.
- **Announcements:** the five newest, with a link to all, right under the cards.
- **My requests:** service requests and incident requests by status (Open, On Hold, Resolved, Closed, **Canceled**, other) with totals, and the five most recent requests.
- **My approvals:** waiting approvals by type, plus *Approved by me* and *Rejected by me*.
- **My loans:** all loans · to return within 30 days · overdue.

Every number opens its page with the matching filter. Canceled requests are now counted without changing any settings. Request figures cover the user's 1000 most recent requests.
