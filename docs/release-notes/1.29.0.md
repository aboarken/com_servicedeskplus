# com_servicedeskplus 1.29.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## New
- **Attachments open in a popup:** images and PDF files on the approval page open over the page, with *Open in new tab*, *Download* and *Close*. Other file types are downloaded as before.

## Changed
- **Change and release approvals work like purchase order approvals:** the decision is recorded under the API technician and nothing is removed afterwards, so the approval is not restarted in ServiceDesk Plus.

## What you may notice
- On phones, some browsers cannot show a PDF inside the popup; use *Open in new tab* or *Download* there.
- On an approved change or release, ServiceDesk Plus shows the API technician's entry as decided, next to the original approver's entry.
