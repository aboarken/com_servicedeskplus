# com_servicedeskplus 1.22.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Dashboard
- **Your details at the top:** Department, Job Title, Employee ID and Name, from the user's own ServiceDesk Plus record.
- **Charts instead of Announcements and Recent Requests:**
  - *Requests by Status* — Open, On Hold, Resolved and Closed, split into incidents and service requests; click a bar to see those requests.
  - *Open Requests by Age* — under 1 week, 1–4 weeks, 1–3 months, over 3 months.
  - *Open Requests by Priority*.
  Each chart shows its numbers, a tooltip on hover and a *Show figures* table. The charts use the requests the Dashboard already reads, so they add no waiting time.
- The Announcements panel and card are removed from the Dashboard (the Announcements page stays), so the Dashboard makes fewer calls to ServiceDesk Plus.
