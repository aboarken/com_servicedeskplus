# com_servicedeskplus 1.24.2

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Changed
- **Clearer message when an approval cannot be recorded.** Users see "ServiceDesk Plus does not allow this decision from the portal. Please contact the System Administrator." when the API technician lacks permission, and the closed-record message only for closed records.
- The log names what to fix: the module (requests, changes, releases or purchase orders) whose **Edit** permission the API technician's role needs in ServiceDesk Plus.
