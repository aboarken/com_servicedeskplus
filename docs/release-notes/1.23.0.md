# com_servicedeskplus 1.23.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes. **Updating is recommended.**

## Security: new matches wait for your approval
Joomla lets users change their own e-mail without verifying it, so an e-mail address alone does not prove who someone is. From this version, when a user opens the portal for the first time, the ServiceDesk Plus user with their e-mail is found but **not used until an administrator approves it**:

- The user sees: *"Your account was found in ServiceDesk Plus and is waiting for an administrator to approve it."*
- **User Mappings** shows how many users wait, with a link to them (status *Waiting for approval*). Check that each e-mail belongs to that person, select the users and click **Confirm** (several at once).
- **Match again** also ends in *Waiting for approval*.

Users already matched keep their access. Mappings you make yourself with **New** are active at once.
