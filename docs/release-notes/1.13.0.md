# com_servicedeskplus 1.13.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Approvals on the request page
When a request has approvals, its page in My Requests now shows them by level: **approver, status, sent for approval, decided on and comments**. The request's **approval status** is shown with its other details. Requests without approvals look as before.

## Announcements as a table
Announcements now look like My Requests: **ID, subject, type, priority, posted by, start date and end date**. Click the ID or subject to open an announcement. You can search (ID, subject or text), filter by type and sort (newest, oldest, ending soonest, subject A–Z); long lists are split into pages of 25.

## Links between portal pages
At the top of My Requests, New Request, My Approvals, My Loans and Announcements there are links to the other pages. Each user only sees links to pages they have permission for. Where a page has a menu item, the link uses the menu item's title.

## Backend
*Integration Settings* and *User Mappings* have a **Close** button that returns to the administrator dashboard.

## Joomla review
- Database queries use `createQuery()` instead of `getQuery(true)`, deprecated since Joomla 5.
- Every site page loads the portal stylesheet, so pages look the same.
- The manifest names the project website.
