# com_servicedeskplus 1.18.2

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Approval comment wording
When someone approves or rejects from the portal and writes a comment, ServiceDesk Plus now shows:

> Approved by (username) Full Name via the Joomla portal. Approval comment: Testing this approval.

Before, the comment followed "Custom comment:". Decisions made earlier keep their old wording in ServiceDesk Plus.
