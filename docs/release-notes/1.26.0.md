# com_servicedeskplus 1.26.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes.

## Dashboard
- **Open Requests by Category**: a bar chart of the user's open and on-hold requests per category (the five largest, then *Other categories* and *No category*). It replaces *Who Is Handling My Requests*.
- **Charts two per row** instead of three (one per row on phones).

## What you may notice
- Right after updating, the chart can say "Shown after the next update of the Dashboard." until the page has refreshed its data.
- If every request shows as *No category*, check `administrator/logs/com_servicedeskplus.php` for "refused fields_required" and send the line to the developer.
