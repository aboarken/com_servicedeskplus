# com_servicedeskplus 1.7.0

Install `com_servicedeskplus.zip` (attached below) through **System → Install → Extensions** in Joomla 6.2 (PHP 8.3+). Upgrading keeps your settings and user mappings and makes no database schema changes.

## Updates from the Joomla backend
- From this version, new releases appear under **System → Update → Extensions** and install with one click; Joomla checks the package's SHA-256 checksum before installing.
- Sites on 1.6.0 or older need to install this version once by hand. After that, updates arrive through Joomla.

## Front end
- **Page titles follow your menu items.** My Requests, New Request, My Loans and My Approvals show the menu item's title as the page heading and browser title. The menu item's *Browser Page Title*, *Show Page Heading* and *Page Heading* settings work as in Joomla core.
- **My Requests:** *Submit a Request* now has the same size as the *Search* button.
- **Request details:** *Technician Group* comes before *Technician*, and every empty field (Priority, Urgency, Technician Group, Technician, Category, Subcategory, Item) shows "Not assigned".

## Backend
- **Settings** is renamed **Integration Settings**, and **User mappings** is renamed **User Mappings**.
- New extension description: "Integrate ManageEngine ServiceDesk Plus with Joomla to provide a centralized IT self-service portal for users."
