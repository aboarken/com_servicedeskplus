# com_servicedeskplus 1.21.0

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). The update adds one database table (`#__sdp_cache`).

## Every page opens at once
When a user's results are older than the cache time, the portal no longer waits for ServiceDesk Plus before showing the page. It shows the user's last results at once, with *"Showing your data from … Updating…"*, then loads the fresh page in the background and swaps it in. This applies to the Dashboard, My Requests, My Approvals, My Loans, Announcements and the detail pages.

- If the user has started typing on the page, nothing is replaced: a *Reload the page* link appears instead.
- If ServiceDesk Plus cannot be reached, the last results stay, marked *"Could not update just now"*.
- A user's own new requests and decisions still show up at once.

## Cache kept in the database
Each user's results are now stored in the database instead of the Joomla session, so they survive logout and session expiry. They are only ever shown to the same user and are deleted after 7 days.

The very first visit of a user (no results stored yet) still waits for ServiceDesk Plus.
