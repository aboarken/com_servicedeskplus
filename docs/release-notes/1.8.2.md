# com_servicedeskplus 1.8.2

Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below) through **System → Install → Extensions**. No database schema changes.

## Fix: approving from Joomla on ServiceDesk Plus On-Premises
1.8.1 sent the approval e-mail with the address used by ServiceDesk Plus Cloud, which ServiceDesk Plus On-Premises does not know ("Invalid URL"), so the decision was still refused with "Recommendation mail is not yet sent." The portal now sends the e-mail the way the On-Premises API documents it (per approval level, with the approval's id), and keeps the Cloud form as a fallback.
